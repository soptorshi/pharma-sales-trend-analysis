# Pharma Sales Trend Analysis

## Project Overview

An interactive Power BI dashboard designed to analyse pharmaceutical sales performance and identify trends in revenue, product sales, and business performance.

## Objectives

* Analyse pharmaceutical sales trends.
* Monitor revenue and sales performance.
* Identify product-level sales patterns.
* Generate actionable business insights through data visualization.

## Tools & Technologies

* Microsoft Power BI
* DAX
* Power Query
* Data Visualization

## Project Files

* `Pharma Sales Trend Analysis.pbix` – Power BI dashboard and analysis.
